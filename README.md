# KEIBA ORBIT

注目する中央競馬の1レースを分析し、上限3万円の**仮想**の購入配分と、note記事作成用の指示を作る個人用ツールです。

- 実際の馬券購入機能はありません。分析結果の的中・利益・売上は保証しません。
- AIの従量課金APIは使いません。Claudeの**通常チャット**へコピーし、応答を貼り戻して使います。
- サーバー不要の静的Webアプリです。データはブラウザ内（IndexedDB）に保存します。
- データの取得元の調査結果は [DATA_SOURCES.md](DATA_SOURCES.md) を参照してください。天気（Open-Meteo）以外は自動取得していません。

## iPad / iPhone で試す手順（PC不要）

### 1. 公開する（初回だけ）

GitHub Pages で無料公開できます（**リポジトリが公開（public）の場合**。非公開リポジトリのPagesはGitHubの有料プランが必要です）。

1. iPadのSafariで GitHub のこのリポジトリを開く。
2. 「Settings」→「Pages」→「Build and deployment」の「Source」を **GitHub Actions** にする。
3. 「Actions」タブ →「Deploy to GitHub Pages」→「Run workflow」を押す（ブランチを選んで実行）。
4. 数分後、緑のチェックになったら、表示されたURL（`https://<ユーザー名>.github.io/keiba_orbit/`）をSafariで開く。
5. 共有ボタン →「ホーム画面に追加」で、アプリのように開けます。

公開したくない場合は、Claude Code に「プレビューを起動して」と頼み、表示されたプレビュー環境で確認してください。

### 2. 架空デモで一通り操作する

1. ホームで「架空デモで試す」を押す（画面上部に「架空デモ表示中」と出ます）。
2. 分析準備で「分析対象と情報締切を確認しました」にチェック →「分析用コピー」。
3. 「結果を貼り付け」→「架空デモの応答を入れる」→「読み込んで確認」。
4. 確認画面で内容を見て「この内容で保存してレポートを表示」。
5. レポートで条件（基本／馬場が悪化／速いペース）を切り替える。「速いペース」は未分析の表示になります。
6. 「note記事作成用コピー」を押し、Claudeに貼り付けて記事を作ってもらう。生成された記事は「生成された記事を貼り戻す」に保存できます。

### 3. 実際のレースで使う

1. ホーム（「新しく始める」）で開催日とレース名を入力。競馬場とR番号は出馬表で確認して選ぶ（推測で選ばない）。
2. 分析準備で、出走表（`4 馬名`、取消は行末に`取消`）、過去成績、馬場、オッズ（単勝 `4 3.2`、ワイド `4-7 2.1-2.8`）を貼り付け、提供者・元URL・取得日時・対象時点を記録して「この内容で反映」。天気は「天気予報を取得（Open-Meteo）」ボタンで取得できます。
3. 情報締切を入力してチェック →「分析用コピー」→「Claudeを開く」→ Claudeに貼り付けて送信。参考画像はClaudeのチャットへ別途添付します。
4. Claudeの応答（JSON）をコピーし、「結果を貼り付け」で読み込む。別レース・版違い・予算超過・合計不一致・取消馬・同じ馬2頭のワイドなどは拒否されます。
5. レース後、「保存した分析」で払戻額（不的中は0）を記録すると収支履歴に入ります。
6. 端末の保存データは消えることがあるため、「JSONで書き出す」で「ファイル」アプリに保存しておくと安心です。

## 集めるデータ（要約は不要）

アプリにもClaudeにも、整えたデータは必要ありません。ページの文字をそのままコピーして貼り付ければ、整理はClaudeが行います。

| 項目 | どこで | どうやって |
| --- | --- | --- |
| 出走表 | JRA公式サイトの出馬表 | 馬番と馬名を `4 馬名` の形で1行ずつ入力（取消は行末に `取消`） |
| 過去成績 | 同じ出馬表ページ（各馬の前走〜4走前が載っています） | ページを全選択してコピーし、そのまま貼り付け（最大60,000文字） |
| 馬場 | JRA公式サイトの馬場情報 | 該当部分をコピーして貼り付け |
| オッズ | 出馬表の単勝オッズ／オッズのページ | 単勝 `4 3.2`、ワイド `4-7 2.1-2.8` の形で入力し、何時時点かを記録 |
| 天気 | アプリ内 | 「天気予報を取得（Open-Meteo）」ボタン |

どの項目も、提供者・元URL・取得日時を記録してから「この内容で反映」を押します。アプリがJRAのサイトへ自動でアクセスすることはありません。

## 仕様のポイント

- 入力（レーススナップショット）と応答はどちらも `schemaVersion: 1`。Zod で検証し、未知フィールド・文字数・配列数・ファイルサイズに上限があります（`src/domain/schema.ts`）。
- 券種は**単勝（win・1頭）とワイド（wide・異なる2頭）のみ**です。全券種には対応していません。
- 金額は100円単位の整数。`spent = 賭け金の合計`、`unspent = 予算 − spent`、`maxLoss = spent` をアプリで再計算し、応答と食い違えば拒否します。
- 払戻目安は、記録したオッズ（取得時点つき）からだけ計算し「未確定」と表示します。ワイドは幅（min〜max）で表示します。出走7頭以下のワイドは払戻条件を確認できていないため保留です。的中確率・期待値・最適配分は計算しません。配分は裁量的な仮説として表示します。
- 貼り付けたJSONは `JSON.parse` のみで読み込み（evalしない）、MarkdownやHTMLは文字として表示します。リンクは http/https のみです。
- 保存した分析は上書きせず版を重ねます。note記事と収支は別の領域に保存し、予想時点の内容は変わりません。
- 日時はすべて日本時間（JST）で表示します。

## 開発

```sh
npm ci
npm run dev        # 開発サーバー
npm test           # 単体テスト（Vitest）
npm run build      # 型チェック + 本番ビルド（dist/）
npx vite preview --port 4173 & npm run e2e   # ビルドをブラウザで通し確認（Playwright）
```

構成：Vite 8 / React 19 / TypeScript / Zod 4。ルーティングはハッシュ方式（`#/report/...`）なので、どのサブパスに置いても動きます。

```
src/domain/    スキーマ・検証・金額計算・テンプレート埋め込み（UIに依存しない）
src/storage/   IndexedDB と JSON入出力
src/data/      天気（Open-Meteo）
src/screens/   ホーム・分析準備・貼り付け・レポート・保存・設定
src/templates/ 分析指示・note記事指示・末尾文・架空サンプル（素材パックのまま）
public/assets/ ロゴ・アイコン・背景・orbit-ui.css（素材パックのまま）
design-kit/    素材パックの仕様書とデザイン見本（preview.html）
```
