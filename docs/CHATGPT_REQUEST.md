# データ収集の依頼文（ChatGPTに貼り付ける用）

以下を、そのまま収集担当のChatGPTに送ってください。形式の詳細は docs/FEED_FORMAT.md にあります。

---

KEIBA ORBIT（受け取る側のアプリ）を更新しました。これまでの形式（schema_version "1.0"）と、これまでにお願いした項目（血統・調教師・馬体重・result）はそのままで、騎手の成績を追加してください。
（下の数値は書き方の例で、実際の成績ではありません。）

【追加する項目】
ファイルの一番上の階層（races や track_conditions と同じ階層）に "jockey_stats" を追加し、その日の出馬表に名前がある騎手全員の、今年のJRA成績を入れてください。出典はJRA公式の騎手リーディング（https://www.jra.go.jp/datafile/leading/ など）。

"jockey_stats": [
  {
    "name": "（出馬表と同じ騎手名）",
    "year": 2026,
    "rides": 512,
    "first": 98,
    "second": 70,
    "third": 55,
    "as_of_jst": "2026-10-31T18:00:00+09:00",
    "source_url": "https://www.jra.go.jp/datafile/leading/"
  }
]

- name は出馬表の jockey と同じ表記にしてください（見習いの記号 ★☆▲△◇ や空白はあってもなくても構いません）。
- rides は騎乗回数、first・second・third は1着・2着・3着の回数（整数）。勝率・複勝率はアプリが計算するので不要です。
- as_of_jst は、ページに書かれている集計の時点（「○月○日現在」など）。分からなければ null。取得した時刻で代用しないでください。
- 載っていない騎手（地方・外国の短期免許で表に出ない場合など）は入れなくて構いません。値が取れない項目は null。

【収集のタイミング】
- 前日の夜（金曜・土曜 21時ごろ）のファイルに入れてください。当日の朝・夜のファイルには入れなくても構いません（前回の値が残ります）。
- 騎手変更があった場合は、当日の朝のファイルに、変更後の騎手の成績を追加してください。

【守ってほしいこと（これまでと同じ）】
- 取得できなかった値は null。推測や仮データで埋めない。
- 時刻は日本時間（+09:00）で、その値を確認したページの時点を書く。確認日（checked_on_jst）とは別。
- 本番データは sample: false。
- JSON以外の説明は collection_notes に入れる。
